---------------

TABLE TAG :
----------
TABLE IS A MATRIX OF ROWS AND COLUMNS. IT MAY HAVE "CAPTION". IT DOESNOT MEAN ANYTHING WITHOUT THE TAGS OF ROWS AND COLUMNS(SALES ARE CALLED TABLE DATA). IT IS A CONTAINER TAG CONTAINING THE TAGS FOR CAPTION, TABLE ROW, TABLE HEAD AND TABLE DATA.

SYNTAX : <table attribute>.....</table>

Attribute:
---------
 
Attributes	  Meaning
width = N or N%	  N IS THE ABSOLUTE SIZE AND N% RELATIVE SIZE FOR TABLE SIZE AND WINDOW FOR EXAMPLE: <table width= 50%> half  of the screen.
border= N	  THIS ATTRIBUTES DRAWS THE TABLE WITH A BORDER OF N PIXELS THICK.
bgcolor	          BACKGROUND COLOUR OF THE ENTIRE TABLE
bordercolor = "color" this attribute sets the border colour of a page.	
cell spacing  = N	this separates cell with a gather of N pixels.
cell padding  = N	separates and the text with a padding of N pixels
align	                 this causes the table to be aligned in one of a variety of ways on a page. here A should should be  one of left /center/ right.
	
a)caption : <caption align = "left|center|right">...</caption>
b) tr : <tr attribute>...</tr> attributes : height = N, bgcolor = color, align = A, valign = V
c)th 
d)td
syntax for th and td : <th attribute> text
a) width = N%
b) height = N
c) bgcolor = color
d) align = A
e) colspan =N
f) rowspan = N
